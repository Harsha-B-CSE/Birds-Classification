Scientific Methodology & Architecture

How Feathered Insights achieves high-precision avian species identification with zero out-of-distribution hallucinations.

1. Vision Transformer Backbone

The core species classification engine is powered by a Swin Transformer (Shifted Windows) model. Unlike standard Convolutional Neural Networks (CNNs), the Swin architecture computes self-attention within shifted local windows, allowing the model to capture fine-grained plumage textures, beak contours, and micro-patterns across 200+ bird species.

Swin-Tiny Baseline Input: 224x224 RGB CUB-200-2011 Dataset

2. Three-Check Verification Cascade

Standard neural networks produce overconfident predictions on non-bird images. Feathered Insights implements a strict 3-tier sequential gate:

  • Check 1 (MobileNetV3 Binary Gate): Filters non-avian inputs (vehicles, domestic animals, random objects) in ~12ms.
  • Check 2 (Species Classification): Generates fine-grained logits across 200 species using the Swin Transformer.
  • Check 3 (Energy-Based OOD Gating): Computes Helmholtz Free Energy to reliably identify novel or uncataloged avian species.

3. Edge & Cloud Infrastructure

Hosted on serverless Google Cloud Run with Firebase Hosting CDN integration. Model weights are optimized via ONNX Runtime CPU execution for sub-second inference latency with zero idle server cost.
